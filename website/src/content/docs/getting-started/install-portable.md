The old `coalesce-labs/catalyst-skills` portable pack is no longer a supported source. Install the current skill packs from their own repositories:

- [`catalyst-dev-skills`](https://github.com/coalesce-labs/catalyst-dev-skills) provides development workflows.
- [`catalyst-cloud-skills`](https://github.com/coalesce-labs/catalyst-cloud-skills) provides Catalyst Cloud tenant setup and operation.

For the default workstation commands and the optional Claude Code plugin rails, see [Install Catalyst skills](/getting-started/). Choose one rail per pack. Do not remove unrelated skills when migrating from the old pack.
